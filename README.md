# سيستم الكافيه

سيستم بسيط لتتبع تكلفة الخامات والمبيعات والأرباح في كافيه. شغال بالكامل في المتصفح (HTML + CSS + JavaScript) بدون سيرفر أو مكتبات.

## المميزات
- **شاشة بيع سريعة:** اضغط على المنتج لإضافته للطلب، ثم «تأكيد البيع». الخامات بتتخصم من المخزون تلقائياً.
- **خامات بوحدات سهلة:** الخامة بتتخزن بالجرام/المللي/القطعة، والشراء تقدر تكتبه بالكيلو أو اللتر أو بالعبوة.
- **منتجات ووصفات:** مع حاسبة «الكيلو بيعمل كام كوب؟» ومعاينة فورية للتكلفة والربح.
- **مخزون:** متوسط تكلفة تلقائي، جرد، وتسجيل الهالك.
- **تقرير شهري:** صافي الربح، الإيراد، تكلفة الخامات، المستهلك من كل خامة، الربح لكل منتج، مبيعات كل يوم، وتصدير CSV يفتح في Excel.
- **نسخة احتياطية** JSON، وبيانات تجريبية للتجربة.

## التشغيل
افتح `index.html` في المتصفح. أو:

```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

## النشر على GitHub Pages
Settings → Pages → Branch: `main` / root.

## ملاحظات
- البيانات في `localStorage` على نفس المتصفح والجهاز فقط. كل رابط (file:// أو localhost أو github.io) له تخزين منفصل، فاستخدم التصدير/الاستيراد للنقل.
- الخطوط من Google Fonts، ولو مفيش إنترنت بيستخدم خط النظام.

## الملفات
- `index.html` الهيكل
- `style.css` التصميم
- `app.js` المنطق والبيانات

## أفكار للتطوير
- مصاريف ثابتة (إيجار، مرتبات)
- تنبيه حد أدنى للمخزون
- تخزين مشترك بين أكثر من جهاز
